# Alke Wallet - Proyecto Integrador

Este repositorio contiene la estructura base para la billetera virtual **Alke Wallet**, desarrollada con HTML, CSS, JavaScript y Bootstrap.

## Archivos del proyecto

* `index.html`: Pantalla de inicio de sesión (Login).
* `menu.html`: Menú principal con saldo y accesos rápidos.
* `deposit.html`: Formulario para realizar depósitos de dinero.
* `sendmoney.html`: Sección para realizar transferencias a contactos.
* `transactions.html`: Historial con los últimos movimientos realizados.
* `css/styles.css`: Estilos personalizados de la interfaz.
* `js/main.js`: Lógica interactiva con jQuery y almacenamiento local (localStorage).

## Tecnologías utilizadas

* HTML5
* CSS3 / Bootstrap 5
* JavaScript / jQuery
